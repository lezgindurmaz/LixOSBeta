# LixOS Beta

LixOS için deneysel işletim sistemi projesi.

## İndirmeler

Varsayılan `main` dalında şu anda proje özeti bulunuyor. ISO kalıpları ve kaynak arşivleri [GitHub Releases](https://github.com/lezgindurmaz/LixOSBeta/releases) bölümünde yayımlanıyor.

Sürüm notlarını ve dosya adlarını kontrol ederek cihazınıza uygun release’i seçin. Bu proje deneysel niteliktedir.
